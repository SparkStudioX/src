SparkStudio 0.2.0-preview.4 - unsigned Windows preview

This package includes the gateway, .NET runtime, browser Designer and operator application, and CPython. No separate SDK, Node.js or Python installation is required to run it.

Current-user extraction (/PORTABLE=1 /CURRENTUSER) is the verified evaluation path. It extracts application files without registering a service, shortcuts or an uninstaller. Use a separate data directory and an unused loopback port; see the installation guide supplied with the release.

On first launch, create an administrator using security/setup-code.txt in the gateway data directory. There are no default credentials. Projects require explicit publication before operators can open them. Accounts, project grants and gateway resources persist on disk.

For a Windows service installation, open PowerShell with Run as administrator on the gateway computer and run:
Get-Content -LiteralPath "$env:ProgramData\SparkStudio\security\setup-code.txt"
Paste the file's code, not its path, into Gateway setup code. Portable, development and container installations use security/setup-code.txt in their configured data directory. The file is removed after initial setup. This release retains preview.3's setup instructions and compact Designer version label; the full build remains available in its tooltip.

Normal installation requests elevation and is designed to create a LocalService Windows service on loopback, with data in C:\ProgramData\SparkStudio. The port can be changed in the wizard. No firewall rule or remote access is enabled. An elevated preview.2 retry after a failed preview.1 installation started successfully as LocalService on one Windows host with retained data. Broader installation, service-account secret encryption and ACL behavior, upgrade recovery and uninstall still require acceptance testing.

This release retains preview.2's fix for preview.1's erroneous 45-second startup timeout caused by anonymously checking the protected /api/health endpoint. The installer uses a direct-loopback-only /api/ready check for product, startup status, bundled Python and process ID. Health details and gateway diagnostics remain protected. Portable extraction and readiness tests do not establish actual elevated service installation acceptance.

Preview.4 also waits for the actual owned gateway process to exit before copying application files. Preview.3 could encounter Access denied for clrjit.dll while the old process was still exiting, even after Windows reported the service stopped, and could require Retry after that process exited. A smooth preview.3 upgrade was not verified.

After a preview.1 startup timeout, back up C:\ProgramData\SparkStudio and retry this installer in the same program directory. Existing data is retained; do not delete it to retry. Use the installer to start the service, or supply an explicit writable --DataDirectory when starting the executable directly.

Back up the complete data directory before upgrading. Connections use Windows account-specific encryption; configure credentials in the target deployment instead of assuming encrypted development data is portable. The installer refuses to adopt an unrelated service or stop a process occupying its chosen port.

The executable is unsigned. Verify its SHA256 checksum from the release. Do not disable Windows security or organization policy to run it. This is a local evaluation preview, not production acceptance.
